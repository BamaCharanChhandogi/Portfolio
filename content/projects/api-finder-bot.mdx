## The Problem

When you're building a project or chatting with teammates on Telegram or mobile, you often need the official docs or base URL for an API (like Stripe, Twilio, or GitHub). Searching on Google usually shows ad-heavy directories and outdated blog posts before you find the actual documentation link.

## How the Bot Solves It

You simply message `@apifinder_bot` with the name of the API (for example, "weather", "auth", or "stripe"). The bot instantly replies with the direct official documentation link, base endpoints, and auth requirements right in Telegram.

## How It's Built

- **Telegram Webhook Architecture**: Responds immediately via webhooks instead of draining battery or CPU with constant polling.
- **Fuzzy Search Index**: Handles typos and partial names so you still find the right API even if you don't remember the exact name.
- **Inline Query Support**: You can type `@apifinder_bot stripe` directly in any group chat to share the documentation link with friends without adding the bot to the group.

## What It Means

A quick, reliable utility that speeds up finding documentation during hackathons and mobile discussions.
