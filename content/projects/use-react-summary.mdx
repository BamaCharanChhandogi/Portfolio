## The Problem

Adding AI text summarization to a React app usually means writing a lot of repetitive code: calling the API, managing loading spinners, catching network errors, formatting the returned markdown, and handling component unmounts. If you have several pages or apps that need summarization, you end up copying and pasting that same logic every time.

## How the Package Solves It

`use-react-summary` wraps that whole process into an easy-to-use custom hook. You simply call:
```tsx
const { summary, loading, error, summarize } = useSummary(apiKey);
```
Pass in your text, and you get back formatted summary text along with loading states ready to plug into your UI.

## How It's Built

- **Custom Hook Pattern**: Standard React hook design with clean state transitions.
- **TypeScript First**: Full type definitions included so you get autocomplete for all options in your editor.
- **Request Cancellation**: Uses `AbortController` so ongoing AI requests cancel cleanly if the user navigates away or types something new.
