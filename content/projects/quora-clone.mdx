## The Problem

Q&A platforms like Quora are deceptively complex under the hood. You have questions with multiple answers, nested comments, live upvote/downvote counts, and topic filters. If your state isn't organized properly, clicking "upvote" on one answer can accidentally re-render the whole screen or cause state sync bugs.

## How It Solves It

This project recreates the full Quora interaction flow to test and master Redux state management:
- Asking questions and submitting answers.
- Upvoting and downvoting with immediate feedback.
- Browsing questions filtered by topics like Technology, Science, and Design.

## How It's Built

- **Redux Toolkit**: Normalizes questions and answers into predictable state slices so updates are clean and isolated.
- **Optimistic UI**: When you click upvote, the number updates on your screen instantly while the action is processed.
- **Modular Components**: Reusable UI cards for questions, user badges, and answer threads.

## What It Means

A hands-on exercise in handling complex, high-density user state without performance lag.
