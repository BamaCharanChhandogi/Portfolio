## The Problem

When developers, students, or study groups are chatting in Discord, someone often has a quick coding question or wants feedback on an error screenshot. Leaving Discord to open an AI browser tab, pasting the code, waiting for an answer, and coming back breaks the group conversation flow.

## How the Bot Solves It

This bot brings Google Gemini straight into your Discord channels. You can use simple slash commands like `/ask` or upload an image and ask what is wrong with it. The bot responds directly in the channel with clean markdown code formatting so everyone in the server can learn from the answer.

## How It's Built

- **Discord.js (v14)**: Uses Discord's official Gateway connection to handle multiple user messages concurrently.
- **Google Gemini API**: Generates code explanations and analyzes image attachments.
- **Sliding-Window Memory**: Keeps track of recent conversation context per channel so you can ask follow-up questions naturally.

## What It Means

A practical community tool that makes AI assistance available where developers already hang out, without needing paid third-party bots.
