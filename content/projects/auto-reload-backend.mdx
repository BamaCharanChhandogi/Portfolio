## The Problem

When developing Node.js backend servers, every small edit in your routes or middleware means stopping the server (`Ctrl+C`), running the start command again, and waiting for it to bind. While tools like Nodemon exist, they often fail with `EADDRINUSE` port clashes or leave orphaned processes running in the background when something crashes.

## How It Solves It

This extension watches your project files and manages the restart process cleanly inside VS Code. When you save a file in `src/` or `controllers/`, it gracefully terminates the old process, frees the port, and restarts the server automatically.

## How It's Built

- **VS Code Terminal API**: Connects directly to VS Code's integrated terminal, sending clean restart signals without creating phantom processes.
- **Debounced File Watching**: Waits a split second after you save to avoid triggering multiple restarts when saving multiple files at once.
- **Status Bar Toggle**: Gives you an easy button in the bottom bar to pause auto-reloading whenever you want.
