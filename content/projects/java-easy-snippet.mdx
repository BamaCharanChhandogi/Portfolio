## The Problem

Java is notoriously verbose. When practicing data structures, algorithms, or preparing for technical interviews, typing out `public static void main(String[] args)`, Scanner declarations, `ArrayList<Integer>`, and loops over and over again wastes time and breaks concentration during timed challenges.

## How It Solves It

Java Easy Snippet adds 60+ intuitive shortcuts inside VS Code. You just type a short prefix and press `Tab`:
- `jmain` expands into a complete runnable main class.
- `jscan` creates a fast Scanner input pattern.
- `jal` sets up an ArrayList with tab stops ready for your data type.
- `jhm` sets up a HashMap.

## How It's Built

- **VS Code Snippet Grammar**: Uses native snippet placeholders so you can tab between variable names and types smoothly.
- **Java-Only Scoping**: Configured to only trigger inside `.java` files so it never gets in the way when editing other file types.
