## The Problem

When you write technical articles with AI assistance (like in Claude Desktop or Cursor), getting the finished post published is still a hassle. You have to open three different browser tabs, paste Markdown, fix formatting quirks, upload headers, and deal with separate API tokens across Hashnode, Dev.to, and WordPress. 

## How BlogCaster Solves It

BlogCaster connects to your AI assistant using the Model Context Protocol (MCP). Instead of manual copy-pasting, you can just tell your AI: *"Publish this article to Hashnode and Dev.to."*

The server takes your Markdown, sets the title, handles tags, preserves canonical links, and publishes everything directly through their official APIs.

## How It's Built

- **Cloudflare Workers**: Hosted at the edge so it runs globally with almost zero latency and no server maintenance.
- **Durable Objects**: Keeps session state and API tokens separate for each user, so credentials never get mixed up.
- **Dual Support**: Works as a hosted cloud endpoint for remote AI clients and as an installable NPM package for local desktop editors.

## What It Means

It turns a tedious 15-minute publishing chore into a single natural-language command inside your editor.
