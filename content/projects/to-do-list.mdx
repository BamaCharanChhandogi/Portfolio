## The Problem

Beginner task apps often lose everything you typed the moment you accidentally close or refresh your browser tab. Building a task app that properly persists state and updates cleanly is the quintessential first milestone in learning React.

## How It Solves It

This is an interactive daily task planner built in React:
- Add, complete, and delete tasks with instant UI updates.
- Automatically saves tasks to your browser's local storage so nothing gets lost.
- Filter between All, Active, and Completed tasks.

## How It's Built

- **React State**: Uses clean state updates to manage the task list without direct DOM manipulation.
- **LocalStorage Sync**: Loads saved tasks as soon as the app mounts.
- **Responsive Styling**: Works cleanly on mobile and desktop screens.

## What It Means

A milestone project that cemented my early understanding of React component state, props, and browser storage.
