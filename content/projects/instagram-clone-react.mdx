## The Problem

Connecting a frontend framework like React to a live cloud database is a big learning hurdle: you have to handle user authentication, file uploads, and make sure new posts and comments appear on everyone's screen in real time.

## How It Solves It

This project builds the basic mechanics of Instagram:
- Users can create accounts and log in securely.
- Upload images with captions.
- Leave comments on posts with updates syncing immediately using live database listeners.

## How It's Built

- **React & Material UI**: Clean mobile-style card layout with avatar icons and action buttons.
- **Firebase Auth**: Manages user accounts and persistent login sessions.
- **Cloud Firestore**: Real-time NoSQL database so posts and comments update live.

## What It Means

A great early milestone in building full-stack applications with real authentication and live cloud storage.
