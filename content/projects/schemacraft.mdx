## The Problem

Whenever you write a new Mongoose model in a Node.js project (like a user, product, or order schema), you have to test the API endpoint. That means opening Postman, looking back and forth at your schema file, and manually typing out a dummy JSON request body with names, emails, dates, and nested objects. It's repetitive and wastes 10–15 minutes per endpoint.

## How SchemaCraft Solves It

This VS Code extension does the work for you with one click. Right-click on any Mongoose schema file in your editor, and it:
- Reads all the fields, types, and validation rules.
- Uses AI to fill in realistic sample data (real-sounding names, valid emails, believable prices).
- Creates a ready-to-import Postman collection or copies the JSON right to your clipboard.

## How It's Built

- **VS Code Extension API**: Runs inside the editor worker thread so it never freezes your coding interface.
- **AST Parser**: Extracts field names, types, and default values directly from the code without needing to connect to a live MongoDB database.
- **Generative AI**: Fills in realistic test values instead of boring dummy text like `"string1"` or `"string2"`.
