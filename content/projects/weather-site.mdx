## The Problem

Checking the weather should be instant, but a lot of online weather tools take seconds to load heavy ad trackers and slow framework scripts before you even see the temperature outside.

## How It Solves It

Weather Site was built using pure vanilla JavaScript with zero frameworks. It asks for your location permission, looks up current coordinates, and immediately displays your local temperature, humidity, wind speed, and weather condition without any lag. You can also search for any city in the world.

## How It's Built

- **Vanilla JavaScript (Fetch API)**: Direct API calls to OpenWeather with zero external packages.
- **Geolocation API**: Auto-detects local coordinates so you don't even have to type your city.
- **Dynamic CSS Styling**: Background and iconography adjust smoothly to match whether it's sunny, rainy, or overcast.

## What It Means

A super lightweight utility that loads in milliseconds, proving that you don't always need heavy frameworks for fast, useful tools.
