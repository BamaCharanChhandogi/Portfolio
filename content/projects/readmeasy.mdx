## The Problem

A lot of developers build great projects but put minimal effort into their GitHub README because writing documentation feels slow and unexciting. As a result, recruiters and other developers skip past the repository because there are no clear setup steps, feature summaries, or screenshots.

## How READMEasy Solves It

READMEasy gives you an interactive form where you just fill in the basics: what the project does, key features, install commands, and tech stack. 

It then generates a complete, clean GitHub README with proper badges, installation code blocks, and markdown structure. You can edit the text and see a live side-by-side preview before copying it to your clipboard.

## How It's Built

- **React & Tailwind CSS**: Clean dual-panel editor with instant markdown rendering.
- **Google Gemini**: Drafts crisp feature explanations and setup guides from your bullet points.
- **Client-Side Only**: Runs fast in your browser without requiring an account or saving your code on external servers.

## What It Means

Helped dozens of developers turn empty, unappealing repos into professional-looking GitHub showcases in under 2 minutes.
