BlogCaster is a cloud-hosted MCP server that enables publish, list, and delete operations across Hashnode, Dev.to, and WordPress.

It uses Cloudflare Workers for the hosted runtime and Durable Objects for per-user token isolation, giving users zero-install remote access from MCP-enabled clients.
